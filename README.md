# Book Store Management System

## Project Description
The Book Store Management System is a software
application developed using Python and MySQL.
It helps manage book details and store records
efficiently.

## Technologies Used
- Python
- MySQL
- Tkinter

## Features
- Manage book details
- Store book information in a database
- Add new books
- View book records
- Update book details
- Delete book records

## Requirements
- Python
- MySQL Server
- Required Python libraries

## How to Run
1. Clone the repository.
2. Install Python and MySQL.
3. Configure the database connection.
4. Run the Python application.
